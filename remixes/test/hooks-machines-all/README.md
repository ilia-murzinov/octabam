# hooks-machines-all (test remix)

ANALOG BD and CX OSC in one image: HOOKS gives the track's machine list seven rows, ANALOG BD on row 5 and CX OSC on row 6, and the list scrolls (SPRING harvested for ANALOG BD). See [HOOKS](../../../modules/hooks/README.md) (`machine_rows`).

OCTA303 + CX OSC is refused (LFO SETUP PMTR name site).

`tools/verify/verify_hooks.py hooks-machines-all` checks the bridged sites in this image after
`make bus REMIX=hooks-machines-all`.
