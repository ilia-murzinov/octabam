# `megabyte` — MEGABYTE

Caroline Megabyte–inspired lo-fi delay replacing stock **DELAY**. ColdFire
rings (Tape Echo seam). Lean voice: distinct knob roles without the CX MB Z
EMAC blow-up that froze the unit.

| Knob | Does |
|---|---|
| TIME | ~50–1200 ms; longer darkens loft |
| FDBK | Stable repeats (alone ≤~0.88) |
| GAIN | Wet preamp into write (drive + softclip) |
| MOD | Chorus on read (~0.5–4 ms); LFO once/block |
| HAVC | Off below ~16; then runaway pull on feedback |
| MIX | Wet over dry; **0 = exact dry** |

Conflicts with TAPE ECHO. `verify_megabyte_cpu` + check.
