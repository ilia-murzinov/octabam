# ilia · octabam

Personal **base** / **cx** remix stacks for the Elektron Octatrack (OS 1.40C).

Built with the **[octabam](https://github.com/sambanks/octabam)** remixer by
[Sam Banks](https://github.com/sambanks) and many contributors. Most of each
image is their modules (CORE, Tim’s machines, Kyoti’s workflow tools, …).
This site documents [the ten modules developed on this fork](reference/modules.md)
and the [builder](web-builder.md). Full authorship: [Credits](credits.md).

## Get started

1. [Build](web-builder.md) — matrix + patch your own 1.40C in the browser  
2. [Credits](credits.md) — who wrote what in these images  
3. [Modules](reference/modules.md) — VOID, SHATTER, CX OSC, SCOPE, …
