# ilia · octabam

Personal **base** / **cx** remix stacks for the Elektron Octatrack (OS 1.40C),
built with the [octabam](https://github.com/sambanks/octabam) remixer.

This site covers **the builder** and **modules developed here**. Everything
else in those images comes from octabam contributors — see [Credits](credits.md).

## Get started

1. [Build](web-builder.md) — matrix + patch your own 1.40C in the browser  
2. [Modules](reference/modules.md) — VOID, SHATTER, CX OSC, SCOPE, …
