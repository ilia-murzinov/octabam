# About

Personal **base** / **cx** remix stacks for the Octatrack, using the
[octabam](https://github.com/sambanks/octabam) remixer. This site covers those
remixes and [modules developed here](reference/modules.md). Reused octabam
work is credited on [Credits](credits.md).
